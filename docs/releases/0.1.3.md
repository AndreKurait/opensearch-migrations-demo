## ma-demo 0.1.3

This patch ships the installer and cleanup fixes merged since 0.1.2.

- Require a valid SHA-256 sidecar and exactly the expected archive member before
  replacing an installed binary. Failed verification preserves the old binary.
- Preserve workspaces containing Terraform state, cloud deployment metadata, or
  an unreadable or empty saved plan.
- Retain local workspaces when KIND cleanup fails, and retain AOSS metadata while
  asynchronous deletion is pending. Validate resource lookups before deleting.
- Build every release asset from the same tag commit. Stage all four platform
  archives and verify checksums and contents before publishing a complete release.
- Derive the source-build development version from package metadata.

Validation includes 214 Rust tests, offline installer and release-asset
regressions, formatting, strict Clippy, and backend-disabled Terraform checks.
Cloud responses are mocked; this release does not add live AWS validation.
Cloud cleanup retains state for operational verification, and Terraform
teardown remains an explicit operator action.

Install using the release's `install.sh` with `MA_DEMO_VERSION=v0.1.3` and a
chosen `BIN_DIR`. Existing version tags and assets remain unchanged.
